# Budgetplan

Ein einfacher Budgetplan im Browser: Lohn, Abos, Fixkosten und weitere Ausgaben eintragen und sehen, was pro Monat übrig bleibt und in welche Kategorien das Geld fliesst.

- Erkennt Einträge wie «Spotify», «Miete» oder «Migros» und gibt ihnen ein passendes Icon und eine Kategorie
- Jährliche oder quartalsweise Kosten werden auf den Monat umgerechnet
- Posten pausieren, um zu sehen, was eine Kündigung bringt
- Sparziel und Sparhinweise
- Daten bleiben im Browser (localStorage); Backup per Kopieren/Einfügen

Starten: `index.html` im Browser öffnen.
